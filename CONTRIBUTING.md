# Video.js® Contributor Guide

This repository is the home of Video.js 8. Open issues and pull requests for Video.js 8 here, in [videojs/videojs-v8](https://github.com/videojs/videojs-v8), and use `main` as the base branch. Do not open them in [videojs/video.js](https://github.com/videojs/video.js), which now hosts Video.js 10.

The general guide below still applies. Where it mentions videojs/video.js, use this repository instead.

Please refer to: <https://github.com/videojs/admin/blob/main/CONTRIBUTING.md>
